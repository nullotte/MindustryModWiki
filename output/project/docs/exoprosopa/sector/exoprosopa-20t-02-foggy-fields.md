# <img src="/exoprosopa/images/sector-exoprosopa-20t-02-foggy-fields.png" width="48" height="48"></img> Foggy Fields
Due to a great number of vents present, the sector has occasional foggy episodes.
The enemy has built a giant base here. It is recommended to bring large amounts firepower.


[accent]Note: This is an optional sector. Capturing it is not required for completing the campaign.
