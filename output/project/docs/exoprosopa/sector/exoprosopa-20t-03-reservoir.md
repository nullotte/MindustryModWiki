# <img src="/exoprosopa/images/sector-exoprosopa-20t-03-reservoir.png" width="48" height="48"></img> Abandoned Reservoir
You land in a cramped sector filled with miasma.
The sensor detects an enemy base in this sector.

Unfortunately, you must build your production and defence between a lake and distorted environment.
Use ship units to dismantle the enemy base before the enemy dismantles you.


[accent]Note: This is an optional sector. Capturing it is not required for completing the campaign.
