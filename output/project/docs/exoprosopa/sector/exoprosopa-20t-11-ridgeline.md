# <img src="/exoprosopa/images/sector-exoprosopa-20t-11-ridgeline.png" width="48" height="48"></img> Ridgeline
Rhodes have built a heavily guarded stronghold here. It remains undefeated for years.
Your goal is to find any exploit and all weaknesses in order to make it fall.


Modifiers:
- Terraformic Basin, Terrafilter & Nichrome Dissembler are unavailable.


[accent]Note: This is an optional sector. Capturing it is not required for completing the campaign.
