# <img src="/exoprosopa/images/sector-exoprosopa-19s-10-precipice.png" width="48" height="48"></img> Precipice
A jagged, fractured canyon formerly used as [accent]Mech Testing Grounds by Rhodes.
The unsupported terrain makes it very hard to build and operate a base.

Utilize [accent]Surge Launcher for transporting resources across the winding terrain.
Be prepared for attacks from multiple directions.
