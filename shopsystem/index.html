    ShopSystemMod v1.4 - Your Personal In-Game Economy!

    🎮 NEW: Press K key or type /shop to access the shop on PC! Mobile users tap the SHOP button!

    ⚠️ MAJOR UPDATE v1.4: Tamper-Resistant Save System, Prestige System, Cosmetics, and Offline Earnings!

    🚨 IMPORTANT: This update will RESET your progress due to the new save system! Sorry for the inconvenience.

    ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    📋 CHANGELOG - What's New in v1.4:

    🔐 Tamper-Resistant Save System:

    • Hash-based save validation

    • Detects and prevents save file editing

    • Auto-resets corrupted saves

    • Value clamping prevents impossible stats

    • Protects against cheating attempts

    🌟 Prestige System:

    • Reset progress for permanent bonuses

    • Earn Prestige Points (PP)

    • 5 Prestige Perks: Coin Master, Pet Expert, Shop Discount, Wave Bonus, Ultimate VIP

    • Unlock exclusive Prestige Crown cosmetic

    • Requirements: Shop Level 15 & 50k earned

    💤 Offline Earnings System:

    • Pets earn coins while you're away (up to 4 hours)

    • Efficiency-based rewards

    • Welcome back dialog shows earnings

    • VIP multiplier applies (50% rate)

    • Prestige bonuses stack

    ✨ Cosmetics System:

    • 6 Visual Effects: Golden Aura, Blue Flames, Rainbow Trail, Lightning Effect

    • 2 Badges: Prestige Crown, VIP Star

    • Equip/unequip cosmetics

    • Unlock via progression or purchase

    • Pure visual, no gameplay advantage

    🔨 Changes & Removals:

    • ❌ Removed Pet Evolution System (too complex)

    • ❌ Removed Daily Login (buggy)

    🐛 Bug Fixes:

    • Fixed save corruption issues

    • Improved data validation

    • Better error handling

    • More stable save/load system

    ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    💰 What's This All About?

    Earn coins by playing the game - killing enemies, completing waves, doing daily tasks. Spend those coins in the shop to buy resources, spawn units, or use special abilities. Now with full support for both Serpulo and Erekir!

    ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    🛒 The Shop Has:

    Serpulo Resources → Copper, Lead, Coal, Titanium, Thorium

    Erekir Resources → Beryllium, Tungsten, Oxide, Carbide

    Serpulo Units → Flare, Dagger, Mace squads

    Erekir Units → Stell, Locus, Merui squads

    Boosts → Skip waves or heal all buildings

    Pets → 13 pets for passive income

    Pet Missions → Send pets for guaranteed rewards

    Auction House → Bid on exclusive items

    Converter → Exchange Serpulo ↔ Erekir resources

    Crafting → Craft advanced materials

    Cosmetics → Visual effects and badges

    Prestige → Reset for permanent power

    Favorites → Star your favorite items

    ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    ⭐ VIP System

    The more you spend, the more VIP EXP you get. Level up your VIP status and earn coins way faster. At max level (VIP 5), you get 6x coins and 25% discount on everything!

    ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    🎮 How Do I Use This?

    PC:

    1. Press K key anywhere

    2. Type /shop in chat

    3. Click Shop button in pause menu

    Mobile:

    1. Tap the SHOP [K] button on the right side of your screen

    Your coins, VIP level, and Shop level are always shown in the UI!

    ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    📈 Ways to Earn Coins:

    Playing the game:

    • Each enemy killed = 1 coin (× VIP level)

    • Each wave completed = 5 coins (× VIP level)

    • Prestige bonuses multiply earnings!

    Daily stuff:

    • Daily Quests → 15-25 coins

    • Daily Challenges → 80-120 coins each (4 challenges)

    • Daily Work → 30-50 coins

    Long-term:

    • Achievements → 50-300 coins

    • Milestone Rewards → 50-3000 coins

    • Pets → 2-100 coins per minute automatically

    • Offline Earnings → Up to 4 hours of pet income

    • Pet Missions → 40-450 coins per mission

    • Auction House → Bid smart and win!

    Secret stuff:

    • Flash Sales → Up to 50% off random items

    • Redeem Codes → Hidden codes for free coins!

    ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
