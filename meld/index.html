    Author Sh1penfire
    Repository https://github.com/sh1penfire/meld
    Stars 44
    Last updated 2026-05-15T07:21:04Z

    An experimental RTS mod. Features a rich environment and a unique cast of enemies to fight.

    Trudge through Ikaru, home to Meld. Salvage the remains of previous incursions. Fend off the wildlife.

    Play as a field commander. Rally tierless specialists to push back the flood of constructs.

    DEFEND, TAKE GROUND, HARVEST, REPEAT

    Campaign is a demo for what's to come. Refer to the custom game maps once you've finished.

    This type of project takes lots of time to develop so if you wana know what's happening with the mod, join the Mindustry discord server and look for Meld in the fourm thread :D

    Alternatively, join the Meld discord server!
    https://discord.gg/eNynvuJXud
